# 🏆 Temple Run - Obsidian & Gold Edition

An endless 3D runner web game inspired by Temple Run, featuring an obsidian black and metallic gold luxury visual aesthetic, WebGL rendering via Three.js, procedural Web Audio API sounds, particle systems, and responsive touch & keyboard controls.

## 🎮 Play Live Demo
👉 **[https://tanvi200980.github.io/temple-run-gold/](https://tanvi200980.github.io/temple-run-gold/)**

---

## ✨ Features
- **Obsidian & Gold Luxury Aesthetic**: Metallic gold armored runner, golden curb rails, obsidian temple pillars with glowing cyan runes.
- **Dynamic 3D Environment**: Infinite tile recycling, atmospheric fog, ambient & directional gold sun lighting.
- **Procedural Animations**: Running limb kinematics, jump arcs, sliding crouches, bank tilt on lane shifts, and foot particle sparkle trails.
- **Power-ups & Collectibles**: 3D Spinning Coins, Magnet (attracts coins), Shield (absorbs 1 collision), 2X Score Multiplier Gem.
- **Web Audio API Synth**: Procedural coin chimes, jump swooshes, crash impacts, and rhythmic temple drum beats.
- **High Scores**: Saved automatically in browser `localStorage`.

---

## 🕹️ Controls

| Action | Keyboard | Touch / Mobile |
| :--- | :--- | :--- |
| **Move Left / Right** | `←` / `→` or `A` / `D` | Swipe Left / Right |
| **Jump** | `↑` or `W` | Swipe Up |
| **Slide** | `↓` or `S` | Swipe Down |
| **Pause** | `Esc` or `P` | Pause Button |

## 🛠️ Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/tanvi200980/temple-run-gold.git
   ```
2. Open `index.html` in any web browser or serve via local web server:
   ```bash
   python -m http.server 8080
   ```
